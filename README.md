# 2026gsc_KousakuNakagawa
2026年ゼミ論

## Theme

滑空場情報を地図で共有するWebGIS「Glider Open Atlas」の作成

## 1. Introduction

グライダーの訓練では、滑空場ごとに滑走路の配置、発航地点、格納庫、集合場所、周辺の鉄塔・電線などの注意対象、アクセス方法が大きく異なる。しかしこれらの情報は部内資料や口頭説明、紙の地図に分散しており、初めてその滑空場を利用する訓練生が事前に全体像を把握することは難しい。旋回点座標のデータベースは既に存在するが、訓練生が本当に必要とする地上の情報（施設・アクセス・注意対象）をまとめた地図は存在しない。

そこで本研究では、OpenStreetMapのデータを軸に、妻沼滑空場の情報を地図上で確認できる公開型WebGIS「Glider Open Atlas」のプロトタイプを開発する。あわせて航空部員に使ってもらい、訓練前の情報収集に役立つかを確かめる。

## 2. Method

### 2.1 全体概要

- 対象は妻沼滑空場（埼玉県熊谷市・利根川河川敷）に絞る
- 地図データはOpenStreetMapに直接書き込み、Atlas側はそれを取得して表示する
- 背景地図にはOpenStreetMapタイルおよび国土地理院タイル（空中写真）を利用する
- WebサイトはGitHub Pagesで公開する
- 実装はLLMを活用したバイブコーディングで行う

### 2.2 情報の整理

航空部員への聞き取りと部内資料から、訓練生が滑空場について事前に知りたい情報（滑走路・発航地点・格納庫・集合場所・注意対象・アクセス）を整理する。

### 2.3 データ整備

- 整理した情報をOpenStreetMapにマッピングする
- 現地写真を撮影し、地物の説明に添付する（Mapillaryの活用も検討する）

なお、安全に関わる情報は公式資料の代替ではなく、事前学習を補助する参考情報として扱う。

### 2.4 WebGIS開発

OSMデータを地理院空中写真の上に重ねて表示するWebGISをGitHub Pages上に構築する。滑走路や施設をクリックすると説明・注意事項・現地写真が表示される形を目指す。

### 2.5 評価

航空部員（特に妻沼での経験が浅い下級生）に使ってもらい、アンケートとヒアリングで有用性と課題を確認する。

## 3. 今年度の範囲

3年次は妻沼滑空場のプロトタイプ完成までとする。他の滑空場（板倉・角田など）への展開は4年次の課題とする。

## 4. 成果物

- WebGIS「Glider Open Atlas」（GitHub Pages公開）
- 妻沼滑空場周辺のOSMデータ
- 部員による利用評価
- IMRaD型ゼミ論本文（本リポジトリ）

## 5. 4年次への発展

対象を全国の主要滑空場に広げ、各大学航空部が情報を追加・更新できる仕組みへ発展させる。気象情報や空域情報の表示も検討する。
